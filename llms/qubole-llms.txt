# Qubole

> Qubole is a cloud-native data lake platform (now part of Idera) that runs multiple open-source data-processing engines - Apache Spark, Presto, Hive, Hadoop, and Airflow - together in a single, self-managing, cost-optimized environment across AWS, Azure, Google Cloud, and Oracle Cloud. The Qubole Data Service (QDS) exposes a REST API for submitting data commands, managing compute clusters, scheduling jobs, running notebooks/dashboards, and administering accounts, users, groups, and roles. Authentication uses a per-user Qubole API token in the X-AUTH-TOKEN header.

## APIs

- [Qubole Data Service REST API](https://docs.qubole.com/en/latest/rest-api/index.html): Submit and manage Hive/Presto/Spark/Hadoop commands, clusters, schedules, notebooks, and account administration. Base URL https://api.qubole.com/api/v1.2/ (also v1.3, v2; region/cloud-specific hosts available).
